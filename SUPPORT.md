# Support

- **Bug in a product?** Open an issue with the **🐞 Bug report** form on that repo.
- **Feature request?** Use the **✨ Feature request** form.
- **Security issue?** See [SECURITY.md](SECURITY.md), never a public issue.
- **Anything else?** Start a discussion on the repo or contact [@vrahmanov](https://github.com/vrahmanov).
