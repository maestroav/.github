# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful, assume good intent, critique code rather than people, and no harassment of any kind.

## Enforcement

Report unacceptable behaviour privately to the org owner via [@vrahmanov](https://github.com/vrahmanov) on GitHub. Reports are reviewed promptly and handled confidentially. Maintainers may remove, edit or reject contributions and ban contributors who don't follow this code.
