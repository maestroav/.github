# maestroav/.github

Org-wide defaults for **maestroav**.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public org landing page |
| `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `SUPPORT.md` | Default community health files for every repo without its own |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Default issue forms and PR template |
| `workflow-templates/` | Starter GitHub Actions shown under **Actions → New workflow** in every org repo |

Changes here apply to every repo in the org that doesn't override them — keep them short and opinionated.
